# 界面布局设计 v1（像素风 · 两栏结构）

> 风格基准：开罗游戏（Kairosoft）式像素模拟经营
> 替代 `UI框架草图-生成说明.md` 中的三段式布局

---

## 一、分辨率地基（最先定死）

像素风最怕非整数缩放导致的像素糊边。因此采用**低分辨率逻辑画布 + 整数倍放大**：

| 项 | 值 |
|----|-----|
| 逻辑分辨率 | **640 × 360** |
| 默认窗口 | 1280 × 720（×2） |
| 全屏 1080p | 1920 × 1080（×3） |
| 缩放策略 | Godot `stretch/mode = viewport`、`aspect = keep`、`scale_mode = integer` |
| 基准网格 | **32 × 32** 逻辑像素（一个地板 tile） |

**所有下文尺寸均为逻辑像素**，屏幕实际像素 = 逻辑 × 缩放倍数。

美术出图一律按逻辑像素 1:1 绘制，禁止在引擎里缩放贴图。

## 二、整体分区

```
640 × 360 逻辑画布
┌────────────────────────────────────────────────────────┐
│ ① 顶栏 StatusBar                              640 × 24 │
├────────────────────────────────────┬───────────────────┤
│                                    │                   │
│  ② 场景视口 Stage                   │ ③ 经营操作栏 Panel │
│     480 × 336                      │    160 × 336      │
│     （15 × 10.5 tile，可滚动）       │                   │
│                                    │                   │
└────────────────────────────────────┴───────────────────┘
```

宽度比 **75% : 25%**。480 与 160 均为 32 的整数倍，场景与右栏边界永远落在 tile 线上。

右栏定在 160：内容区净宽 144，刚好容纳两列 68px 的上下文按钮（中缝 8）和四列 33px 的模块格（中缝 4），是「不裁内容」的下限。再窄到 128 就得把模块格改成两行四列的小图标，2 字按钮也会挤，得等图标素材到位才有条件压。

**取消底部导航栏**：模块入口收进右栏下半区。理由是 360 的纵向空间极其紧张，再切一条 24~32px 的底栏，场景就只剩 300 出头，网吧全貌装不下。

## 三、① 顶栏 StatusBar（640 × 24）

一行到底，垂直居中，左右各 8px 内边距。

```
┌──────────────────────────────────────────────────────────────┐
│ [LOGO] │🖥机位 12/40│💰资金 500│👥顾客 3│⭐声誉 3.5│🧹清洁 42│🛋装修 50│ │第1天·上午│🔔 ⚙│
└──────────────────────────────────────────────────────────────┘
   65      ←────────────── 指标组（弹性）──────────────→        65     28
```

| 区 | 内容 | 宽 |
|----|------|-----|
| 左 | 品牌 Logo + 店名「猫网电竞」 | 65 |
| 中 | 6 项指标：机位 / 资金 / 顾客 / 声誉 / 清洁 / 装修 | 弹性 |
| 右前 | 天数 · 时段 | 65 |
| 右 | 消息铃 + 设置 | 14 + 14 |

- 每项指标为 **图标 + 文字标题 + 数值** 三段。纯图标辨识成本高，标题是必需的
- 图标 **12 × 12**；标题 8px 暗金 `#dcc08a`，数值 9px 亮奶油 `#ffe9c9`，靠明度差分主次
- 指标之间插 **2px 竖线**（左 1px `#4a2c16` + 右 1px `#a8742e`，高 14），在木纹底上呈现刻线凹槽感；时段前也插一条
- 组内间距 3，组与竖线间距 5
- 数字用等宽像素字，避免跳数时抖动
- 金钱为负变红并抖动；声誉、清洁跌破阈值变橙色告警
- 消息铃有事件时叠 3×3 红点角标

## 四、② 场景视口 Stage（480 × 336）

**正交俯视 + 家具带侧面**的伪 2.5D（开罗的经典做法，比真等距好画、好对齐）。不使用 45° 等距菱形。

### 网格与地图

- 地板 tile：32 × 32；设施、隔板、NPC 与装修槽位吸附 16 × 16 子网格
- 视口可见 15 × 10.5 个地板 tile，即 30 × 21 个物件子格
- **初期 40 台刚好装进视口**，不必拖动；成长期扩店后面地图大于视口，再开平移
- 扩建后地图建议 **20 × 14 tile** 起

### 物件占位规范

| 物件 | 占地 | 说明 |
|------|------|------|
| 电脑机位 | 2×2 子格内组合 | 连续桌面 + 隔板 + 独立显示器/主机/椅，锚点按16px吸附 |
| 收银吧台 | 3 × 1 | 老板站位在后侧 |
| 小卖部货架 | 2 × 1 | |
| 包间隔断 | 沿 tile 边 | 墙体画在格线上，不占格 |
| 顾客 | 点状 | 16 × 24 小人，走16px子格中心路径 |

### 状态可读性

机位顶部挂 **6 × 6 状态点**：空闲绿、使用中蓝、故障红、脏污黄。不靠文字，一眼扫全场。

顾客头顶按需冒气泡（要点单 / 要结账 / 不满），气泡 16 × 16。

### 交互

- **默认选中：柜台位**。进入游戏、开店后、以及单击场景空白处，右栏一律落在柜台视图（老板站位 + 收银操作）
- 单击机位 / 顾客 / 货架 → 右栏切换为该对象的特写与操作
- 再点空白或点回柜台 → 右栏回到柜台默认态
- 拖动平移地图，滚轮不缩放（像素风固定 1:1）

## 五、③ 经营操作栏 Panel（160 × 336）

整块面板是一台 2005 年的老电脑外壳（材质规范见本节末）。机身九宫格四边各占 4px 内衬，因此 160 × 336 的外框内实际可用 **152 × 328**，自上而下五段填满这 328：

```
┌────────────────┐
│ 对象标题条  20 │  默认：柜台 ｜ 切到：3 号机 / 顾客小王
├────────────────┤
│                │
│ 特写视窗   102 │  CRT 框吃 3px，屏内净 96 放 144×96 插画
│                │
├────────────────┤
│ 柜台概览    64 │  琥珀屏框吃 3px，内 58 = 标题 14 + 数据 44
├────────────────┤
│ 上下文操作  64 │  上留 6 下留 4，2 × 2 键帽每颗 68 × 24
├────────────────┤
│ 全局模块    78 │  4 × 2 小键（33 × 24）+ 走带键行 22
└────────────────┘
```

特写视窗取 102 而非 96 是硬约束：CRT 机框上下各占 3px，屏内必须剩满 96，插画才能 1:1 显示。一旦屏内不足 96，144 × 96 的插画会被 `KEEP_ASPECT_CENTERED` 按 0.9375 倍缩小，像素立刻糊边。

宽度上机身内衬后净宽 152，但按钮仍按 144 排布（两列各 68 + 中缝 8；模块四列各 33 + 中缝 4），在 152 内居中，左右各留 4px 机身。

### 材质与配色（复古电脑风）

素材由 `godot/tools/gen_panel_theme.py` 程序化生成，1x 输出到 `godot/assets/ui/panel/`，全部是小尺寸可平铺图，靠 `StyleBoxTexture.texture_margin` 撑开，中心区纯色保证平铺无缝。

| 部件 | 素材 | margin | 说明 |
|------|------|--------|------|
| 机身外壳 | `panel_case.png` 16² | 4 | 泛黄米白塑料，顶高光 + 底 2px 阴影，四角像素螺丝 |
| 特写 CRT 框 | `screen_frame.png` 10² | 3 | 中性深灰机框 + 内圈黑边，屏内不做偏色 |
| 概览琥珀屏 | `amber_frame.png` 10² | 3 | 深墨内凹，底沿一线余晖 |
| 上下文键帽 | `key_{normal,hover,pressed,disabled}.png` 12² | 4 | 凸起键帽四态 |
| 模块 / 走带小键 | `modkey_{normal,hover,pressed,disabled}.png` 8² | 2 | 同款更薄 |

键帽的面色分**亮 / 中 / 暗三段**，配上顶高光、底阴影和描边共六层。只用「描边 + 1px 高光 + 2px 阴影」在 1x 下会显得像框线图，立不起来。三段面色只画在九宫格的上下 margin 区内，中心行保持纯色，因此拉伸时层次不会被拉花。

按下态把顶部高光换成内阴影、底部只留一线反光，整颗键读作凹陷；禁用态换冷灰面并抹平层次。

| 用途 | 色值 |
|------|------|
| 塑料机身 / 高光 / 阴影 / 描边 | `#d8cfb4` / `#efe8d2` / `#9a9078` / `#4a4438` |
| 机身螺丝 | `#5f5749`（带 `#c4bca4` 高光） |
| CRT 机框 / 屏内底 | `#3d3a33` / `#1a1712` |
| 琥珀屏底 / 标签 / 数值 | `#241c10` / `#c8912f` / `#ffc257` |
| 键帽面 / 顶高光 / 底阴影 | `#cfc5a8` / `#e8e0c6` / `#8e8471` |
| 键帽文字 / 禁用文字 | `#2a2419` / `#5c584f` |
| 状态灯 | 绿 `#7ea84e` / 红 `#c0392b` / 黄 `#d4a017` |

概览区做琥珀单色而非经典绿，是为了和顶栏金色、特写插画的暖棕统一；状态灯保留红绿黄，是这块屏上唯一的彩色信息点。

### 动作 icon

由 `godot/tools/gen_action_icons.py` 生成到 `godot/assets/ui/icons/`，动作 icon 10 × 10、走带 icon 8 × 8。

**一律画成纯白剪影**，在 Godot 里靠 `icon_normal_color` / `icon_disabled_color` 调制成键帽文字色 `#2a2419` 或禁用灰 `#5c584f`。这样一套素材同时服务可点与禁用两态，禁用时 icon 会跟着文字一起压灰，不必额外出图。

同义动作共用一张图：接待与响应都走 `serve`，收银与结算都走 `cash`，补货与快捷补货都走 `restock`。开店 / 打烊两态图不同（卷帘门升起 / 落下），由 `_show_counter` 显式传 icon 覆盖映射表。

10 × 10 的画布下一律取最强轮廓特征，不追求写实。几个踩过的坑：收银画钞票或硬币都会被误读成相机，换成 **¥ 字形**才立刻可读；调价的价签画出来像盾牌，换成**上下双向箭头**；预览的眼睛画成圆形会被当成圆按钮，必须**压扁成橄榄形**；库存原本是横纹矩形，和打烊的卷帘门撞形，改成**项目符号加条目行**的清单样式。

键帽是米白塑料，**文字必须用深墨** `#2a2419`；同理时间行的时钟文字直接压在机身上，也走深色。禁用态同时改三件事——冷灰面、去掉高光与阴影、字色压到 `#5c584f`——三重差异叠加才能在 9px 字号下一眼分辨。

### 各段细节

**对象标题条**：深色底 + 金色 12px 像素字，右侧一个小类型徽标（店 / 机 / 客 / 财等）。默认文案「经营总台」，徽标「店」。

**特写视窗（144 × 96 素材）**：**默认态画柜台正视**——吧台台面、收银机、老板与布偶猫。选中机位则换成该机与在座顾客；选中顾客展示其立绘与心情。这是右栏的情绪担当，别只放数据。

**营业概览（160 × 64）**：内嵌琥珀单色屏。顶 14px 标题条，下文键值分行，左标签 `#c8912f`、右数值 `#ffc257`。默认态固定三行：
```
营业总览
状态     休息中   ← 关店红 / 营业绿 / 收尾黄
在店顾客 3 人
今日营收 ¥ 186
```
待接待和待结账人数直接写在两颗副键上。切到机位改为「机位概览」，切到顾客改为「顾客概览」。

**上下文操作**：普通对象保持 2×2；经营总台单独改为第一行 144×24 全宽营业主键，第二行两颗 68×24 高频任务键。每颗键帽是 **icon + 文字**。

按钮区上方必须留 **6px 机身**：概览屏和键帽都有深色描边，紧贴时两条边会糊成一条粗线，第一行按钮看着像是从琥珀屏里长出来的。另外键帽在 `GridContainer` 里要显式设 `SIZE_SHRINK_CENTER`，否则会被拉满整段高度（68px 两行时每颗被撑到 32 高，这是早期版本按钮显得笨重的原因）。

按钮内容随对象变化：
- **经营总台**：开店营业或停止接客或关店结算 / 待接待 / 待结账
- 选中机位：开机或关机 / 清洁 / 维修 / 详情
- 选中顾客：接待 / 结算 / 升会员 / 劝离
- 选中货架：快捷补货 / 查看库存 / 调价 / 促销
- 选中待装修区：预览 / 规划 / 解锁条件 / 留空

**全局模块（4 × 2 图标格，每格 33 × 24）**：财务 / 员工 / 设备 / 采购 / 策略 /
餐饮 / 建设 / 猫咪。设置只保留顶栏齿轮，事件只走消息铃。每颗小键使用 10×10 单色
图标加两个 8px 汉字；当前模块保持按下态。点击后先在右栏展示摘要、指标和四个一级入口，
数据密集的深层页面后续再打开居中弹窗。

时间控制是录像机走带键（暂停 / 播放 / 快进，各 24 × 20），用 8 × 8 像素 icon，
与时钟同占底部 22px 一行。

有未读的模块（如新事件、待发工资）在图标右上叠红点。

按钮的显示条件、禁用条件与预期功能详见 `docs/ui/操作区功能规划.md`。

## 六、弹窗规范

模块详情走**居中弹窗**，不切换主界面，保持网吧始终可见。

| 弹窗 | 尺寸 | 用途 |
|------|------|------|
| 大（财务 / 人力 / 机器） | 512 × 288 | 表格类，带滚动 |
| 中（采购 / 档案） | 384 × 240 | 列表 + 详情 |
| 小（事件抉择 / 确认） | 288 × 160 | 一段文字 + 2~3 个选项 |

弹窗底部压半透明黑遮罩（不遮顶栏），标题条高 20，关闭按钮 12 × 12 在右上。

事件抉择弹窗是策划里的博弈核心，需配事件插图（256 × 96）。

## 七、字体与配色

### 字体

中文像素字必须用 **12px 点阵中文字体**，不能靠缩放普通字体：
- 推荐 **Zpix（最像素）** 或 **Fusion Pixel 12px**，均开源、覆盖简体中文
- 正文 / 按钮：12px
- 数值：12px 等宽
- 强调标题：12px 加描边（描边 1px，不要用大字号）

在 640×360 下 12px 字撑满 ×2 后等效 24px，1080p 下 36px，可读性没问题。

### 配色（延续 05 年怀旧暖调）

| 用途 | 色值 |
|------|------|
| 顶栏 / 面板底 | `#5c3a20` → `#3f2a18` |
| 面板描边 / 分隔 | `#b8860b`（暗金） |
| 主文字 | `#ffe9c9` |
| 高亮文字 | `#ffcf7a` |
| 地板 | `#e8d5a8` / `#dcc795` 双色格 |
| 状态·空闲 | `#7ea84e` |
| 状态·使用中 | `#3a8fc5` |
| 状态·告警 | `#c0392b` |
| CRT 霓虹点缀 | `#ff9a00`、`#3ad1c8` |

调色板整体控制在 **32 色以内**，像素风的统一感来自限色。

## 九、Godot 实现要点

- `project.godot` 设 `window/size/viewport_width=640`、`height=360`，`window/stretch/mode="viewport"`、`aspect="keep"`、`scale_mode="integer"`
- 贴图导入统一关闭 mipmap 与过滤：`filter=false`，否则像素边缘发虚
- 顶栏、右栏用 `Control` + 九宫格 `StyleBoxTexture`；场景视口用 `SubViewport` 承载可平移地图
- 指标数值由 GameManager 发 signal 驱动，UI 不主动轮询
- 数值变化用 Tween 做飘字与颜色过渡，帧率锁 60
