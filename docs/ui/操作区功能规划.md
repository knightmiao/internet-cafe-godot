# 右侧操作区功能规划 v2

> 对应 640×360 主界面右侧 160×336 操作区。  
> 本文定义按钮含义、显示条件和模块边界；具体数值公式另行设计。

## 一、交互原则

1. **半自动经营**：点击开店后自动启动所有正常机器。玩家处理故障、脏污、顾客需求和经营决策，不逐台做重复劳动。
2. **高频一键、复杂进面板**：接待、结算、清洁等高频动作直接执行；采购、调价、升级等需要选择的动作打开小面板。
3. **上下文按钮固定 2×2**：按钮随当前选中对象变化；无意义的操作禁用，不显示假按钮「——」。
4. **操作必须有反馈**：成功后立即刷新场景状态点、对象概览和顶栏；失败时说明缺少的资金、库存或前置条件。
5. **入口不重复**：设置只保留顶栏齿轮；事件走消息铃；右下固定八个经营系统。

## 二、上下文操作

### 2.1 经营总台（默认态）

经营总台不是普通对象的 2×2 操作，而是“一颗全宽营业主键 + 两颗高频任务键”：

- 休息中：`开店营业`；副键为 `开店检查`、`日结回顾`。
- 营业中：`停止接客`；副键为 `待接待 N`、`待结账 N`。
- 收尾中：停止新客进入，现有顾客统一进入结账队列；顾客清空后开放 `关店结算`。
- 日结完成后记录营业日、营收和服务顾客数，天数加一并回到休息态。

开店检查真实统计待清洁、故障与可营业机位；员工和库存尚未实现时明确标记“待接入”，
不伪造检查结果。补货、收银等业务分别由采购模块和顾客上下文承接。

### 2.2 机位

| 按钮 | 类型 | 预期功能 | 启用条件 |
|------|------|----------|----------|
| 开机 / 关机 | 一键动态 | 关机状态显示开机；空闲状态显示关机 | 使用中禁止强制关机 |
| 清洁 | 一键 | 将待清洁恢复为空闲；关店时恢复为关机 | 仅待清洁状态 |
| 维修 | 一键 | 支付维修费，将故障恢复为空闲或关机 | 仅故障状态且资金足够 |
| 详情 | 小面板 | 查看配置、游戏库、历史收益；后续可进入升级 | 始终可用 |

机位状态统一为：**已关机 / 空闲 / 使用中 / 待清洁 / 故障**。  
状态点颜色：灰 / 绿 / 蓝 / 黄 / 红。

### 2.3 顾客

| 按钮 | 类型 | 预期功能 | 启用条件 |
|------|------|----------|----------|
| 接待 / 响应 | 一键动态 | 排队时分配机位；有需求时响应需求 | 状态为待接待或有需求 |
| 结算 | 一键 | 结算网费、商品消费和会员优惠 | 状态为待结账 |
| 办会员 | 小面板 | 选择会员档位和充值金额 | 顾客未达到最高会员 |
| 劝离 | 确认弹窗 | 处理违规或特殊顾客，可能影响声誉 | 顾客仍在店内 |

### 2.4 小卖部货架

| 按钮 | 类型 | 预期功能 |
|------|------|----------|
| 快捷补货 | 小面板 | 补充低库存商品 |
| 查看库存 | 小面板 | 查看现存、销量和缺货预警 |
| 调价 | 小面板 | 调整商品售价与毛利 |
| 促销 | 小面板 | 设置限时折扣或套餐 |

柜台「补货」是低库存快捷入口；完整供应商选择与采购单管理归入全局「采购」。

### 2.5 待装修区域

| 按钮 | 类型 | 预期功能 |
|------|------|----------|
| 预览 | 小面板 | 查看解锁后的布局、台数与预估收益 |
| 规划 | 跳转模块 | 打开「升级」模块并定位到扩区项目 |
| 解锁条件 | 小面板 | 展示资金、声誉、天数等条件 |

第四格留空。条件满足后「规划」变为「开始装修」。

## 三、全局模块

全局模块固定为 4×2 网格，采购只负责买入，设备、餐饮和猫咪负责实际运营：

| 位置 | 模块 | 预期功能 |
|------|------|----------|
| 1 | 财务 | 今日账单、收支趋势、成本结构、日结 |
| 2 | 员工 | 招聘、排班、员工状态、培训 |
| 3 | 设备 | 机器配置、维修、网络软件、游戏库 |
| 4 | 采购 | 小卖部、餐饮原料、硬件软件、猫咪用品 |
| 5 | 策略 | 网费、商品价、会员促销、广告 |
| 6 | 餐饮 | 菜单、订单、制作设备、食品卫生 |
| 7 | 建设 | 装修、服务升级、扩区、区域主题 |
| 8 | 猫咪 | 状态、喂养、用品、顾客互动 |

### 建设模块首版：装修目录

- 点击「建设 → 装修」进入场景装修预览，12 个预设槽位显示青色虚线；高配区锁定槽显示红色。
- 点击槽位后，右栏按标签轮播兼容项目，四键固定为「上一项 / 购买或安装 / 下一项 / 退出」。
- 中央键根据状态显示价格、安装、已安装、资金不足、等级不足或区域未解锁。
- 购买成功立即扣款、登记持有并安装；已持有项目换槽或替换时不重复收费。
- 右栏同时展示装修、清洁、舒适、声誉和客流加成，顶栏余额、装修、清洁和声誉即时刷新。
- 大厅、包间、高配区主题独立；锁定高配区允许浏览主题详情，但不能安装。

### 入口分工

- **顶栏消息铃**：通知与待办列表，只负责提醒和跳转。
- **随机事件**：由消息铃弹出决策，结果归入财务或经营档案，不占常驻模块。
- **顶栏齿轮**：唯一设置入口。

## 四、时间控制

| 控件 | 功能 |
|------|------|
| Ⅱ | 暂停模拟时间 |
| ▶ | 正常速度 1× |
| ≫ | 快进 2×；后续可扩展 4× |

暂停不影响 UI 操作。事件抉择和确认弹窗默认自动暂停。

## 五、MVP 实现顺序

1. 语义动作 ID、按钮禁用状态和统一反馈。
2. 柜台开店 / 打烊与机位自动启停。
3. 机位开关、清洁、维修及状态点刷新。
4. 顾客接待、结算与今日收银闭环。
5. 财务模块和日结。
6. 八模块首页与一级导航；深层经营数值按财务、员工、设备、采购顺序落地。
