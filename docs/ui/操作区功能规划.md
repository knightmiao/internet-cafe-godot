# 右侧操作区功能规划 v3

> 对应 640×360 主界面右侧 160×336 操作区。  
> 本文定义按钮含义、显示条件和模块边界；单日经营闭环的数值见 `godot/data/sim_tuning.json`。

## 一、交互原则

1. **半自动经营**：点击开店后自动启动所有正常机器。柜台自动接待和结账，但要耗时；人多就得雇前台。玩家处理故障、脏污和经营决策。
2. **高频一键、复杂进面板**：清洁、维修等高频动作直接执行；招聘、采购、调价等打开小面板。
3. **上下文按钮固定 2×2**：按钮随当前选中对象变化；无意义的操作禁用，不显示假按钮「——」。
4. **操作必须有反馈**：成功后立即刷新场景状态点、对象概览和顶栏；失败时说明缺少的资金、库存或前置条件。
5. **入口不重复**：设置只保留顶栏齿轮；事件走消息铃；右下固定八个经营系统。

## 二、上下文操作

### 2.1 经营总台（默认态）

经营总台不是普通对象的 2×2 操作，而是“一颗全宽营业主键 + 两颗高频任务键”：

- 休息中：`开店营业`；副键为 `开店检查`、`日结回顾`。
- 营业中：`停止接客`；副键为 `排队 N`、`结账 N`，只负责跳到对应顾客。接待和结账由柜台自动办理，各耗时若干分钟；办理位 = 老板 + 已雇前台。
- 收尾中：停止生成新客，进行中会话按已用时长出账并转入结账队列；排队未上机者直接离店。顾客清空后开放 `关店结算`。
- 日结读取当日流水，记录营收、支出、服务人数、脏污/故障台数，天数加一、自动存档并回到休息态。

开店检查真实统计待清洁、故障与可营业机位；员工和库存尚未实现时明确标记“待接入”，
不伪造检查结果。补货、收银等业务分别由采购模块和顾客上下文承接。今日营收改读 `Ledger`，不再用余额差或按在线台数滴假钱。

### 2.2 机位

| 按钮 | 类型 | 预期功能 | 启用条件 |
|------|------|----------|----------|
| 开机 / 关机 | 一键动态 | 关机状态显示开机；空闲状态显示关机 | 使用中禁止强制关机 |
| 清洁 | 一键 | 将待清洁恢复为空闲；关店时恢复为关机 | 仅待清洁状态 |
| 维修 | 一键 | 支付维修费，将故障恢复为空闲或关机 | 仅故障状态且资金足够 |
| 详情 | 小面板 | 查看配置、游戏库、历史收益；后续可进入升级 | 始终可用 |

机位状态统一为：**已关机 / 空闲 / 使用中 / 待清洁 / 故障**。  
状态点颜色：灰 / 绿 / 蓝 / 黄 / 红。

### 2.3 顾客

| 按钮 | 类型 | 预期功能 | 启用条件 |
|------|------|----------|----------|
| 接待 / 结算 | 展示 | 柜台自动办理，按钮只显示剩余分钟 | 始终禁用，防止跳过耗时 |
| 响应 | 一键动态 | 有需求时响应需求（点单等，尚未接入） | 状态为要点单或有需求 |
| 办会员 | 小面板 | 选择会员档位和充值金额 | 顾客未达到最高会员 |
| 劝离 | 确认弹窗 | 处理违规或特殊顾客，可能影响声誉 | 顾客仍在店内 |

### 2.4 小卖部货架

| 按钮 | 类型 | 预期功能 |
|------|------|----------|
| 快捷补货 | 小面板 | 补充低库存商品 |
| 查看库存 | 小面板 | 查看现存、销量和缺货预警 |
| 调价 | 小面板 | 调整商品售价与毛利 |
| 促销 | 小面板 | 设置限时折扣或套餐 |

柜台「补货」是低库存快捷入口；完整供应商选择与采购单管理归入全局「采购」。

### 2.5 待装修区域

| 按钮 | 类型 | 预期功能 |
|------|------|----------|
| 预览 | 小面板 | 查看解锁后的布局、台数与预估收益 |
| 规划 | 跳转模块 | 打开「升级」模块并定位到扩区项目 |
| 解锁条件 | 小面板 | 展示资金、声誉、天数等条件 |

第四格留空。条件满足后「规划」变为「开始装修」。

## 三、全局模块

全局模块固定为 4×2 网格，采购只负责买入，设备、餐饮和猫咪负责实际运营：

| 位置 | 模块 | 预期功能 |
|------|------|----------|
| 1 | 财务 | 今日账单、收支趋势、成本结构、日结 |
| 2 | 员工 | 招聘前台（增加同时办理人数、关店发日薪）、排班/培训仍占位 |
| 3 | 设备 | 机器配置、维修、网络软件、游戏库 |
| 4 | 采购 | 小卖部、餐饮原料、硬件软件、猫咪用品 |
| 5 | 策略 | 网费、商品价、会员促销、广告 |
| 6 | 餐饮 | 菜单、订单、制作设备、食品卫生 |
| 7 | 建设 | 装修、服务升级、扩区、区域主题 |
| 8 | 猫咪 | 状态、喂养、用品、顾客互动 |

### 建设模块首版：装修目录

- 点击「建设 → 装修」进入场景装修预览，12 个预设槽位显示青色虚线；高配区锁定槽显示红色。
- 点击槽位后，右栏按标签轮播兼容项目，四键固定为「上一项 / 购买或安装 / 下一项 / 退出」。
- 中央键根据状态显示价格、安装、已安装、资金不足、等级不足或区域未解锁。
- 购买成功立即扣款、登记持有并安装；已持有项目换槽或替换时不重复收费。
- 右栏同时展示装修、清洁、舒适、声誉和客流加成，顶栏余额、装修、清洁和声誉即时刷新。
- 大厅、包间、高配区主题独立；锁定高配区允许浏览主题详情，但不能安装。

### 入口分工

- **顶栏消息铃**：打开消息层。上面是待办（待清洁 / 故障，点一下跳到对应机），下面是已处理事件。有未读或未决事件时亮红点。
- **随机事件**：营业中每天最多抽一条，自动暂停并弹出二选一（或知道了）。结果改钱、声誉或当天客流，写入流水和收件箱，不占八模块。测试模式不自动抽。
- **顶栏齿轮**：唯一设置入口。打开居中设置层（不挡顶栏），营业时间自动暂停；再点齿轮、Esc、遮罩或「返回游戏」关闭并恢复原速度。可切换窗口/全屏、窗口尺寸小/中/大（2×/3×/4×，超出桌面则下压）、音效音量与静音、切走暂停；立即存档、读取存档、重新开局（后两项需确认）。面板列出经营快捷键。偏好写入 `user://settings.json`。
- **音效**：Autoload `Sfx` 按 `godot/data/sfx_catalog.json` 播短音；设置滑条打 SFX 总线。UI 是提示音，开店/上机/结账等是店内纯音效。音乐未做。

## 四、时间控制

| 控件 | 功能 |
|------|------|
| Ⅱ | 暂停模拟时间 |
| ▶ | 正常速度 1× |
| ≫ | 快进 2×；后续可扩展 4× |

暂停不影响 UI 操作。事件抉择和确认弹窗默认自动暂停。

快捷键写死、不改键。设置或确认打开时只认 Esc。

| 键 | 动作 |
|---|---|
| 空格 | 暂停 / 恢复上次非零速度 |
| 1 / 2 | 1× / 2× |
| 回车 | 当前时段主键：开店 / 停止接客 / 关店结算 |
| Esc | 关确认 → 关设置 → 开设置 |
| Z | 远近景切换 |
| WASD / 方向键 | 平移相机（0.5 倍全店时锁居中） |
| C | 回到经营总台 |
| F | 下一台待清洁，没有则跳故障 |
| K | 当前选中待清洁机则清洁 |
| R | 当前选中故障机且钱够则维修 |

存档仍走设置里的「立即存档」。接待/结账没有热键。

## 五、MVP 实现顺序

1. 语义动作 ID、按钮禁用状态和统一反馈。
2. 柜台开店 / 打烊与机位自动启停。
3. 机位开关、清洁、维修及状态点刷新。
4. 顾客接待、结算与今日收银闭环。
5. 财务模块和日结。
6. 八模块首页与一级导航；深层经营数值按财务、员工、设备、采购顺序落地。

### 5.1 单日经营闭环进度

- **已接入**：时钟与走带键、客流生成/排队、柜台自动接待与结账（耗时、办理位）、招聘前台与日薪、机位会话、心情三态、包夜一口价、下机脏污故障、日结电费、柜台三态、财务「今日账单 / 今日电费 / 日结」、装修与维修入账、关店存档、顶栏设置（暂停、音效、全屏、窗口小/中/大、存档/开局）、经营快捷键（空格/回车/Z/WASD/C/F/K/R）、消息铃与第一批随机事件、基础音效。
- **仍占位**：员工排班/培训、采购、策略（定价/会员/广告）、餐饮、猫咪；财务的收支趋势和成本结构。
