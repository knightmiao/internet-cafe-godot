# 猫网电竞 · 初期店面规划

> 依据县城常规网吧调研（证照齐全、普通规模）。本文件只定**开局小店**，后续阶段在此基础上扩。

## 调研结论（游戏里怎么用）

| 现实体量 | 台数 | 对应游戏阶段 |
|----------|------|----------------|
| 偏小门店 | 40～60 | **初期开局：40 台** |
| 标准门店 | 70～90 | 成长期目标 |
| 县城电竞馆 | 100～150 | 扩张期，少见、投资高 |
| 回本下限 | ＜40 很难活 | 开局不往下压 |
| 包间占比 | ≤ 总台数 30% | 初期只放 20% |

县城工作日大厅为主、包间易空，所以开局**不要堆包间**。周末包间才爆，后期再加开黑房。

## 开局配置：40 台

| 分区 | 间数 | 机位 | 说明 |
|------|------|------|------|
| 普通大厅 | — | **32** | 基础配置，LOL / CF / DNF，密集、便宜，客流基本盘 |
| 电竞高配区 | — | **0** | 场内留「待装修」空地，成长期解锁 |
| 双人包（情侣/双排） | **2** | **4** | 隔断、稍贵，初期两间够用 |
| 四人开黑包 | **1** | **4** | 县城最吃香，开一间试水，避免空置 |
| 五/六人战队房 | 0 | 0 | 占地大、空置高，小店不做 |
| 无烟区 / 直播专区 | 0 | 0 | 面积不够，后期可选项 |
| 水吧（柜台+货架） | — | 不算机位 | 前台收银、零食饮料 |

- 大厅 32 + 包间 8 = **40**
- 包间机位 **8 / 40 = 20%**（低于 30% 红线）
- 面积感：按 2.5㎡/台含过道，约 **100㎡** 级小店，比标准 80 台 / 220㎡ 明显更破、更挤

## 场内平面（视口 480×336，初期不滚动）

落地采用 **32×32 地图格 + 16×16 物件子网格**。地板与区域仍按 32px 组织，
联排桌、隔板、NPC 和装修槽位吸附 16px 子格，解决 40 台全部使用 32px 整格时
密度过低的问题。详细坐标见 `docs/ui/核心场景设计.md`。

```
┌──────────────────┬──────────┬──────────────┐
│ 普通大厅 8×4=32   │ 待装修   │ 双人包 A 2台 │
│                  │ 高配区   ├──────────────┤
│                  │ （空地） │ 双人包 B 2台 │
│                  │          ├──────────────┤
│                  │          │ 四人开黑 4台 │
├──────────────────┴──────────┴──────────────┤
│ 入口 + 收银柜台 + 小卖部 + 主走道 + 卫生间       │
└────────────────────────────────────────────┘
```

机位编号：大厅 01～32，双人 A 33～34，双人 B 35～36，四人房 37～40。

大厅机位采用连续桌面、联排隔板、独立显示器/主机/椅子的组件化拼接；主走道
净宽至少 32px。装修第一阶段使用预设槽位，经营态隐藏空槽，不允许装修物件
改变碰撞或阻断入口、柜台、包间与卫生间之间的通路。

## 下一阶段预留（先不摆进场景）

- 成长期：大厅扩到 40～48，高配区开 8～12 台，再加 1 间四人包 → 总台约 60～80
- 扩张期：战队六人房 1 间、无烟角落；总台冲 100；包间仍压在 30% 内
