# 猫网电竞 · 核心场景设计

> 场景世界 960×672；舞台视口 480×336，靠相机两档缩放取景。
> 地板基准格 64×64，设施与角色吸附 32×32 子网格。

## 一、设计目标

- 开局 40 台全部可见、可辨认、可点击。
- 电脑呈现真实县城网吧的连续桌面、联排隔板、显示器与椅子，而不是 40 个独立方按钮。
- 入口、柜台、小卖部、卫生间、大厅和包间之间保留连续 64px 主走道。
- 相机两档：0.5 倍一屏看满整店，1.0 倍近景看细节，按住左键拖拽平移，滚轮切档。
- 装修采用预设槽位，正常经营时隐藏，不允许家具阻断寻路。

### 像素美术语言

场景素材分两条管线，各自解决不同问题：

- **生图 → 像素化**（家具、设施、装修件、角色）。先用生图模型画高分辨率概念稿，
  再由 `import_stage_concepts.py` 抠底、降采样、统一调色板。质感、光影和色彩层次来自
  原画，这是画风能和柜台立绘同源的根本原因。详见 `素材生图管线.md`。
- **代码生成**（地板、墙体、状态点、气泡、选中框）。地板墙体要无缝平铺，生图给不出
  可对接的边缘；状态点气泡是功能反馈，颜色必须精确可控。这两类留在
  `gen_stage_tiles.py` 里逐像素控制。

无论走哪条管线，都要满足：

- 像素风不等于“低分辨率框线图”。场景物件必须由受光顶面、中间固有色、暗侧面和落地投影组成，禁止给每个物件统一套一圈矩形描边。
- 深色轮廓只用于角色外轮廓、显示器边缘等需要从背景中分离的位置；桌面、墙体、货架依靠色面和局部阴影分层。
- 64px 是逻辑地图格，不是地砖图案尺寸。普通地面只显示稀疏低对比磨石子颗粒，不画格线，相邻两格底色必须完全相同——只要有明度差，平铺后就会拼出一张 64px 大棋盘。
- 重复设施必须有局部变化：显示器亮度、状态灯、桌面划痕、商品颜色和人物服装打破机械复制感。
- 设施尽量拆成具体物件。卫生间由湿区地面、洗手台、厕位、门牌组合；高配锁定区由围挡、施工木牌和杂物组合，不用大矩形色块表达区域。
- 机位场景小图必须用接近 70 度的陡俯视，并控制在 64×68。3/4 视角纵深过大会让四排互相遮挡。

## 二、坐标与层级

场景划分为 30×21 个 32px 子格，坐标原点在左上角。

| 区域 | 像素范围 | 内容 |
|---|---|---|
| 普通大厅 | x=32～544，y=32～480 | 四排，每排 8 台，共 32 台 |
| 待装修高配区 | x=544～672，y=32～480 | 围挡空地，预留 8～12 台 |
| 包间区 | x=672～960，y=32～480 | 双人 A、双人 B、四人开黑 |
| 服务区 | x=0～960，y=480～672 | 入口、柜台、货架、等候、卫生间 |

服务区高度按卫生间素材的 192px 定死，营业区拿走剩余纵向空间。

渲染分四层：

1. `FloorLayer`：64px 地板与区域皮肤。
2. `WallLayer`：外墙、包间隔断、高配区围挡、区域标签。
3. `WorldLayer`：机位、设施、NPC、装修槽，**开启 `y_sort_enabled`**。
4. `SelectionLayer`：选中框。

设施和 NPC 共用一个 y_sort 层是关键：前后遮挡按纵坐标自动成立，老板站在柜台后面
就会被柜台挡住下半身，顾客走到柜台前面就压在柜台上。若拆成两层再用固定 z_index，
柜台后的老板会浮在柜台前面。

```text
┌──────────────────────────┬──────────┬────────────┐

│ ─────── 主走道 ───────── │ 围挡     ├────────────┤

│ 17 18 19 20 21 22 23 24  │          │ 35  36    │
│ ─────── 主走道 ───────── │          ├────────────┤
│ 25 26 27 28 29 30 31 32  │          │ 四人开黑  │
│                           │          │ 37 38 39 40│
├───────┬──────────┬───────┴──────────┴──────┬─────┤
│ 入口  │ 收银柜台 │ 小卖部 / 等候 / 主走道   │卫生间│
```

大厅每排 8 台按两组 4 座排列。每台使用独立的 64×68 完整套装（显示器、主机、
键鼠、桌椅），因此以后可以逐台换代；初始 40 台全部绑定 `gen_09`。

排中心线为 y = 88 / 200 / 312 / 424，间距 112 = 68 桌深 + 44 走道。
座位锚点按 64px 横向节拍排列，点击热区 60×64，不覆盖相邻座位。

## 四、通路规则

- 主走道净宽至少 1 子格（32px），排间走道 44px。
- 入口到柜台、大厅、包间门和卫生间必须连通。
- 顾客站位取子格中心；设施碰撞占整子格，装饰碰撞不得侵入主走道。
- 包间门口前方保留至少 2×2 子格回转空间。
- 柜台前保留两个排队点，队列向主走道方向延伸。

## 五、交互规则

- 点机位、顾客、柜台、货架或高配区，向主界面发送 `object_selected(kind, id)`。
- 点场景空白回到柜台默认态。
- 当前选中对象显示 1px 金色像素框；机位状态点分五态：
  - 已关机灰 `#77736a`
  - 空闲绿 `#7ea84e`
  - 使用中蓝 `#3a8fc5`
  - 待清洁黄 `#d4a017`
  - 故障红 `#c0392b`
- 顾客气泡只在需要处理时出现，避免 480×336 画面被文字覆盖。

## 六、装修槽位

`godot/data/decor_catalog.json` 固化首批 24 项：6 套区域主题、6 项功能设施、
5 项舒适家具、4 组氛围装饰和 3 项服务升级。每项统一包含槽位标签、价格、解锁等级、
场景素材、144×96 详情图和装修 / 清洁 / 舒适 / 声誉 / 客流五类加成。

初期预埋 12 个可点槽位：

| 槽位 | 类型 | 兼容内容 |
|---|---|---|
| hall_floor_a / b | floor | 绿植、座椅和落地家具 |
| hall_utility | utility | 空调、新风、售货、饮水和充电设施 |
| entrance_wall / hall_wall / room_wall | wall | 灯牌、海报、旗帜、隔音与墙面设备 |
| counter / shelf / restroom_service | service | 柜台、货架和卫生间的一对一升级 |
| hall / rooms / highend_skin | zone_skin | 六套区域主题 |

空槽在经营态隐藏；进入升级模块后全部显示青色虚线，已装槽仍可点击替换。点击槽位后
右栏只轮播标签兼容的项目，并处理等级不足、资金不足、已拥有、已安装和区域未解锁状态。
购买先扣款并加入持有列表，随后安装；持有项目再次安装不重复收费。

大厅、包间和高配区各自保存主题 ID。换肤会重建该区域的 64×64 地板与 32×32 横竖墙
覆盖层，不影响其他区域。高配区未开放时可浏览六套主题，但安装键保持禁用。

顾客资料保存在 `godot/data/customers.json`，每个 ID 与同编号 sprite 一一对应。
字段包括姓名、性别、年龄、职业、着装风格、身高、发型发色和结构化上网习惯。
同屏仍只摆放符合店面容量的在店顾客，完整 50 人库供后续客流生成器抽取。

六代机位资料保存在 `godot/data/pc_configs.json`，按 GTX 960、GTX 1060、
RTX 2060、RTX 3060、RTX 4060、RTX 5060 建立升级阶梯。场景节点持有
`config_id`，小图和右栏详情都从同一条配置读取，避免升级后两处显示不一致。

代码生成产出：

- `tiles/floor_atlas`：64×64 四格，普通地板 A/B、卫生间湿区、高配区裸水泥。A/B 底色相同，只有颗粒分布不同。
- `tiles/wall`、`tiles/wall_v`：32×32，横墙纵墙各一，单向无缝。
- `themes/<主题 ID>_floor`：六套 64×64 无缝地板。
- `themes/<主题 ID>_wall` / `_wall_v`：六套 32×32 横竖墙。
- `feedback/state_*`：12×12 状态点，五态。
- `feedback/bubble_*`：32×32 需求气泡，符号用 3px 以上实心块，保证 0.5 倍相机下仍可读。
- `feedback/selection`：64×64 四角金色角标。
- `decor/slot`：32×32 青色虚线空槽指示。

所有素材按 1:1 逻辑像素输出，关闭过滤与 mipmap，调色板控制在暖棕、米白、青蓝和少量状态色内。

## 八、相机

- 档位 `[0.5, 1.0]`，默认 0.5 一屏看满整店，滚轮切到 1.0 近景。
- 0.5 倍时视野 960×672 正好等于世界尺寸，相机被锁死居中，不会拖出黑边。
- 1.0 倍时视野 480×336，按住左键拖拽平移，边界由 `Camera2D` 的 limit 与手动 clamp 双重约束。
- 拖拽超过 4px 就不再判定为点选，避免平移完顺手改了右栏内容。
- 拉远到 0.5 倍时隐藏机位编号与区域标签：10px 字号缩一半后只剩 5px，读不出来反而变噪点。
