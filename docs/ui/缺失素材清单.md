**特写素材工作流**（`portrait_counter` 已验证，其余特写沿用）

1. 生图模型出概念稿，存入 `docs/ui/concept/`。提示词要求横构图、大像素块、限定色数、无文字，并写明角色形象设定
2. `godot/tools/pixelize_portrait.py` 裁掉外框、居中裁成目标比例、区域平均降采样、量化到 32 色
3. `godot/tools/gen_counter_portrait.py` 按坐标重画眼镜、眼睛、鼻嘴和猫的蓝眼。降采样会把这些高对比细节抹平，必须手工补
4. 验收看 2x（游戏内实际显示尺寸），不要放大到 8x 以上抠细节，会过度纠结

新增 PNG 后需执行 `godot --headless --path godot --import`，否则 `load()` 会报 no loader found。

## 字体

- 需要引入 Zpix 或 Fusion Pixel 12px 简体中文字体
- 正文与按钮：12px
- 顶栏受空间限制可使用 8～10px 的配套小号点阵字
- 当前使用系统字体，仅用于布局阶段

## 导入规则

- PNG 使用无损导出，透明背景
- Godot 纹理过滤关闭，禁止 mipmap
- 像素素材不在引擎内做非整数缩放
- Sprite sheet 帧之间不留半透明像素
- 全项目调色板控制在 32 色左右
