# 游戏 UI 框架草图 · 生成说明

## 项目
网吧经营模拟游戏（Godot 4.7 · 2D 平面视图）

## 画面基准
- **分辨率**：1280 × 720（16:9 横屏）
- **渲染**：GL Compatibility（2D）

## 整体布局分区（已确认）

```
┌─────────────────────────────────────────────────────────┐
│ ① 顶栏 TopBar（高 ~54px，横跨全宽）                       │
│   [网吧名] [天数/日期] [资金¥] [顾客数] [声誉★★★]          │
├─────────────────────────────────────────────────────────┤
│                                                         │
│   ③ 主场景·俯视平面图                ④ 侧视·吧台操作区    │
│   （网吧全貌 2D 俯视，约 918×606）   （常驻面板，宽 ~362px)│
│   · 机器棋盘（大厅机器）             · 吧台/收银台特写      │
│   · 包间区域                        · 当前顾客/订单        │
│   · 收银台 / 小卖部                 · 操作按钮快捷栏（底部）│

│                                                         │
```

## 交互逻辑
- **③ 主场景俯视图**：玩家看网吧全貌，做布局与规划；客人在此实时走动
- **④ 右侧侧视面板（常驻）**：平时显示吧台/收银台特写；点选俯视图中的机器/客人/吧台时，切换为该对象的侧视特写
- **操作按钮快捷栏**固定在右侧侧视面板**底部**
- 两个视角联动：俯视图选中目标 → 右侧侧视图显示特写 + 可操作按钮

## 设计基调
- 05 年怀旧网吧感：暖色木纹、复古霓虹点缀
- 信息一目了然：顶栏全局状态、底部模块导航、右侧操作
